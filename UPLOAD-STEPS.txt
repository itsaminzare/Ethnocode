HOW TO UPLOAD (GitHub repo: itsaminzare/Ethnocode)

Your repo's top level must end up looking like this:

  api/claude.js      <- inside a folder called "api"  (THIS is what fixes the 404)
  App.jsx
  main.jsx
  index.html
  package.json
  vite.config.js
  vercel.json

1. On GitHub: Add file -> Upload files.
   Drag in: App.jsx, main.jsx, index.html, package.json, vite.config.js, vercel.json
   Commit changes.

2. On GitHub: Add file -> Create new file.
   In the name box type exactly:   api/claude.js
   (typing the "/" creates the folder)
   Open api/claude.js from this zip in Notepad, copy everything, paste it in.
   Commit changes.

3. In Vercel: Settings -> Environment Variables must contain
   ANTHROPIC_API_KEY = your sk-ant-... key
   Then Deployments -> top entry -> ... -> Redeploy.

4. When it says Ready: open the site, press Ctrl+Shift+R, click Generate codes.
